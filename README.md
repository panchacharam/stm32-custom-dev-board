# STM32 Custom Development Board

A custom STM32-based PCB designed using KiCad.

---

## Overview

This project is a compact STM32 development board created for learning PCB design, embedded systems, and STM32 hardware development.

The board includes:

- STM32 microcontroller
- USB interface
- 3.3V regulator
- Crystal oscillator
- GPIO headers
- Decoupling capacitors
- Two-layer PCB routing

---

## Tools Used

- KiCad 9
- STM32CubeIDE
- GitHub

---

## Features

- 2-layer PCB
- Compact PCB layout
- USB power support
- STM32 minimum system design
- Custom routing
- Ground plane
- 3D PCB visualization
